Backend academico com dados Lattes

Uma API para organizar producao academica e pesquisa.

Este trabalho integra extracao, transformacao e armazenamento de curriculos academicos, permitindo consultar pesquisadores, artigos, areas de pesquisa, formacoes, orientacoes e producoes em eventos por meio de uma API Flask documentada com OpenAPI/Swagger.
